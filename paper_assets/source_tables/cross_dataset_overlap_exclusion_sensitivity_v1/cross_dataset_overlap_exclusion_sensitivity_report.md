# Cross-Dataset Broad Visual-Overlap Exclusion Sensitivity

Excluding the 241 DFUC2021 images involved in broad DFUC2021-DFUC2022 pHash/dHash candidate pairs did not materially change the retained grouped OOF ranking: the selected prior-informed probability-fusion candidate achieved Macro-F1 0.9635 on 5714 retained images, compared with 0.9576 for the retained strong RGB comparator and 0.9557 for the retained strong RGB plus prior-informed residual comparator; the selected-candidate Macro-F1 differences remained positive (+0.0059 and +0.0078, respectively).

## Interpretation Boundary

Strong comparator files are retained grouped OOF comparator predictions from `outputs/grouped_retraining`, not the final-use point-estimate comparator rows in the main grouped-results table. Full OOF prediction files are not redistributed in the public package; they can be regenerated by rerunning the grouped prediction and final-asset scripts.
